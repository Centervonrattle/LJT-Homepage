# LJT-Homepage

Personal academic website of Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Publishing

Every push to `master` is verified by the **Jekyll build** workflow. To publish the site, enable GitHub Pages once (Settings -> Pages -> Source: **GitHub Actions**) and then run the **Deploy Jekyll site to Pages** workflow from the Actions tab.
